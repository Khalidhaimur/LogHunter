# LogHunter
SOC Log Analyzer

Overview

LogHunter is a Python-based SOC-style log analysis tool designed to detect suspicious activities inside authentication and web server logs.

The tool analyzes logs and detects:

Brute force attacks
Password spraying attempts
Suspicious reconnaissance activity
Failed login attempts
Suspicious IP behavior

This project is excellent for:

SOC portfolios
GitHub cybersecurity projects
Blue Team learning
Python practice
SIEM logic understanding

# LogHunter

A Python-based SOC Log Analyzer designed to detect suspicious activities such as brute force attacks, password spraying, and reconnaissance behavior.

# Features

- Detect brute force attacks
- Detect password spraying
- Detect reconnaissance activity
- Analyze SSH authentication logs
- Analyze Apache access logs
- Generate security reports
- Beginner-friendly SOC project
